# Task Force Hellcat Website written in Svelte

[![](https://img.shields.io/website?down_color=red&down_message=offline&label=TFHC%20Homepage&up_color=green&up_message=online&url=https%3A%2F%2Ftaskforcehellcat.de%2F)](https://taskforcehellcat.de)

## Setup

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm (bundled with Node.js)

### Install

```bash
npm install
```

### Run

```bash
npm run dev
```
